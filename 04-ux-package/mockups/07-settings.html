Security policies

  • SSO · OIDC via Entra ID · MFA enforced ✓
  • Per-tenant KMS-wrapped keys · BYOK supported ✓
  • RoE signature requires WebAuthn (FIDO2) ✓
  • Sandbox: Firecracker microVM for all destructive replay ✓
  • Egress: deny-by-default; only ledger TSA + customer-approved endpoints allowed ✓
  • OWASP LLM Top 10 (2025) controls mapped: prompt-injection isolation, output validation, supply-chain pinning

Audit & retention

  • Evidence ledger retention · 365 days (PDPA-aligned)
  • Scan trace retention · 90 days
  • Auto-redaction of Thai PII (citizen ID, phone, banking) before export · ✓
  • DPO co-sign required for regulator bundle export · ✓
  • Tamper-evident: append-only PG + Merkle chain + RFC 3161 timestamp
  • Right-to-erasure workflow available per PDPA §28–§32
